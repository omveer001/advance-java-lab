# Advance Java Lab

A collection of Advance Java laboratory programs and practicals covering core concepts of Java Enterprise programming. This repository is designed for students to learn, practice, and understand Advance Java through hands-on examples.

## 📚 Topics Covered

- JDBC Connectivity
- Servlet Programming
- JavaServer Pages (JSP)
- Session Management
- Cookies
- Request Dispatcher
- File Handling
- Exception Handling
- MVC Architecture
- Database Operations (CRUD)
- Login & Registration System
- JavaBeans
- Networking Basics

## 🛠 Technologies Used

- Java (JDK 17+)
- Eclipse IDE / IntelliJ IDEA
- Apache Tomcat
- MySQL Database
- JDBC
- HTML

- JSP & Servlets

## 🚀 Getting Started

### Prerequisites

- Java JDK 17 or later
- Apache Tomcat Server
- MySQL Server
- Eclipse IDE / IntelliJ IDEA

### Installation

1. Clone the repository:

```bash
git clone https://github.com/omveer001/advance-java-lab.git
```

2. Import the project into Eclipse or IntelliJ IDEA.

3. Configure Apache Tomcat.

4. Create the required MySQL database.

5. Update the database username and password in the JDBC connection file.

6. Run the project on Tomcat Server.
